# 📚 Grand Prix Library Management System

A modern **Library Management System** built using **HTML, CSS, JavaScript, TypeScript, React, Vite, and Node.js** with separate portals for **Admin**, **Employee**, and **User**.

---

## 🚀 Features

### 👨‍💼 Admin Portal
- Add / Remove Books
- Manage Users
- Track Issued Books
- Employee Management
- Library Analytics Dashboard

### 👨‍🔧 Employee Portal
- Issue Books
- Return Books
- Search Books
- Update Availability
- Manage Requests

### 👤 User Portal
- Browse Books
- Search by Author or Title
- View Due Dates
- Track Issued Books
- Responsive Premium UI

## ⚡ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/grand-prix-library.git
```

### 2️⃣ Open Project Folder

```bash
cd grand-prix-library
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run Frontend

```bash
npm run dev
```

### 5️⃣ Run Backend

```bash
node server.ts
```
